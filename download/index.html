Prefer to self-host?
See the Docker images below.

Run the UltraSync server on your own machine and keep the whole thing in your hands: accounts, end-to-end encrypted sync and the account dashboard. Point the apps at your own HTTPS address instead of the official service.

  • Docker Engine with Compose, and a domain with HTTPS.
  • An email service (SMTP) for sign-in messages.
  • Sign-ups on a new server are closed until you open them.
  • Use the pinned image tag. There is no latest tag and no stable 1.0 yet.

Before you run it.

Windows downloads are unsigned and macOS downloads are not notarized by Apple, so your system may ask for confirmation the first time. Checking the SHA-256 checksum shows you have the file we published.

The apps have no analytics. Desktop builds check GitHub once a day for a newer version, and you can turn that off in Settings. The privacy policy has the details.

  • Windows

    If SmartScreen says “Windows protected your PC”, choose More info, then Run anyway.

  • macOS

    If macOS blocks the app, open System Settings, go to Privacy & Security and choose Open Anyway.

  • Linux

    Make the AppImage executable with chmod +x. If it will not start, your distribution may need FUSE.

  • Android

    Allow installs from your browser or file manager when Android asks. The APK is signed with the project’s release key.
