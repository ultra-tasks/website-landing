Move from Todoist
to Ultra Tasks.

Export each Todoist project as a CSV file, then import it from Settings. Your tasks arrive as a new project, and nothing in Todoist or in your existing Ultra Tasks data is touched.

By Adrian Chase · Updated 6 November 2026 · Checked against Ultra Tasks 0.2.0

In short

  • It is a one-time import from a file, not a live sync with Todoist.
  • The app reads the file on your computer. It needs no Todoist login and no API token.
  • It only adds a project. To undo it, delete that project.
  • Dates, repeating tasks and completed tasks need a look afterwards. The lists below say exactly what to check.

Before you start

  • Install Ultra Tasks 0.2.0 or newer. The built-in file importers arrived in that release.
  • Have your Todoist projects open in the web or desktop app, where Todoist’s help describes the export.
  • Decide on the project names you want. The name of each CSV file becomes the name of the new project in Ultra Tasks.

Step 1. Export a project from Todoist

  1. Open the project in Todoist.
  2. Select the three-dot menu at the top right.
  3. Choose Import & export, then Export to CSV.
  4. Repeat for every project you want to move. Todoist exports one project per file.

Todoist leaves completed tasks out of CSV exports, so they will not come across. Todoist’s own page, Import or export a project as a CSV file, has the current menu wording. Rename each file now if you want a different project name, for example Groceries.csv becomes a project called Groceries.

Step 2. Import the file into Ultra Tasks

  1. Open Settings, then Import & export.
  2. In Import from, choose Todoist. The export steps appear below it.
  3. Choose the CSV file. Ultra Tasks shows a preview with the project and task counts. Nothing is written yet.
  4. Check the counts, then select Import tasks.
  5. Look at the new project before you import the next file. Import one file at a time.

Step 3. Check the result

A two-minute look catches almost everything:

  • The task count matches the preview, and subtasks sit under the right parents.
  • Your labels appear as tags, and priorities as p1 to p3 tags.
  • Open a few tasks that had dates. If a date is missing from the schedule, search the task’s notes for a line starting with DATE:. That is where the importer keeps dates it could not read exactly. Set them again with Planned for.
  • Recreate any repeating tasks you rely on. See how repeating tasks work.

What carries over

In Todoist In Ultra Tasks
Tasks and subtasks Tasks and subtasks. Anything nested deeper than two levels becomes a direct subtask of its top-level task.
Descriptions and comments Task notes.
Sections The section name is kept in the notes of each task in it. Sections are not recreated.
Labels Tags, on top-level tasks.
Priorities p1, p2 and p3 tags on top-level tasks. Todoist’s p4, which means no priority, stays untagged.
Duration A time estimate, when the duration is in minutes.
Exact due dates A scheduled date, when the file holds a calendar date written as YYYY-MM-DD, such as 2026-12-15.

What does not carry over

  • Completed tasks. Todoist does not include them in project CSV files.
  • Repeating tasks and dates written in words, such as “every Friday”. The importer does not guess. It keeps the original text in the task’s notes after DATE:, and you set the schedule again.
  • Time zones, deadlines and assignee names. They are kept as text in the notes. Ultra Tasks does not recreate deadlines or assignees from them.
  • Reminders and attached files. They are not recreated.
  • Labels and priorities on subtasks. Only top-level tasks get tags.

Dates are the part to read carefully. Before importing, you can open the CSV in a spreadsheet and look at the DATE column. Values written as YYYY-MM-DD will be scheduled. Others will land in the notes.

If something goes wrong

  • To undo an import, delete the project it created.
  • Importing the same file twice creates duplicates. Delete the extra project.
  • If an import stops partway, check the project named in the message and any projects already imported from that file. Delete those copies before you try the file again.

Questions

Do I need a Todoist API token?

No. Ultra Tasks reads the CSV file you exported. It never signs in to Todoist.

Will this change anything in my Todoist account?

No. The importer only reads the file. Keep your Todoist account and the CSV files until you are happy with the result.

Will the two apps stay in sync?

No. The import is one-way and happens once. Changes you make in Todoist afterwards do not appear in Ultra Tasks.

Can I import all my projects at once?

Not in one step. Todoist exports a project per file, and Ultra Tasks imports one file at a time, so repeat steps 1 and 2 for each project.

Is there an importer for TickTick too?

Yes. It is in the same place in Settings. Read the TickTick import reference for what it brings across.

This guide follows the Ultra Tasks import reference and the importer in version 0.2.0. How your dates look depends on how Todoist wrote your file, so trust the preview and the notes check above over any general rule.
